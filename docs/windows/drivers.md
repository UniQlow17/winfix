# drivers — драйверы

Ищет проблемные устройства, показывает устаревшие драйверы, находит и устанавливает обновления
через Windows Update, делает резервную копию драйверов и точку восстановления.

## Запуск

- Главное меню `winfix` → «Драйверы».
- `winfix drivers` — меню; `winfix drivers report` — проверки без изменений; остальные команды — в таблице ниже.

## Команды

| Команда | Пункт меню | Что делает | Права админа |
|---|---|---|---|
| `problems` | Проблемные устройства | Устройства со статусом не «OK» и кодом проблемы (`CM_PROB_*`) с подсказками | нет |
| `inventory` | Инвентарь драйверов | Сторонние драйверы старше 3 лет, число неподписанных. Встроенные заглушки (дата 1968/2006) пропускаются | нет |
| `search` | Поиск обновлений | Запрос драйверов в Windows Update (COM-API WUA) | нет |
| `install` | Установить найденные | Скачивает и ставит выбранные из поиска; предлагает точку восстановления | **да** |
| `backup` | Резервная копия | `pnputil /export-driver *` → `%LOCALAPPDATA%\WinFix\backups\drivers-<дата>\` | **да** |
| `restore-point` | Точка восстановления | `Checkpoint-Computer` (Windows разрешает 1 точку в сутки) | **да** |
| `ghosts` | «Призрачные» устройства | Записи об отключённых USB/мониторах/адаптерах; удаление через `pnputil /remove-device` | **да** |
| `report` | Полная проверка | problems → inventory → search | нет |
| `links` | Где скачать вручную | Подсказки по NVIDIA / Intel / OEM | нет |

Права администратора запрашиваются (UAC) только когда они реально нужны.

## Рекомендуемый порядок

1. «Полная проверка» (`report`).
2. Если в Windows Update есть нужный драйвер — резервная копия (`backup`) → установка (`install`).
3. Перезагрузка.

## Важно

- **Не ставьте драйвер, у которого дата старше уже установленного** (например, Realtek 2017 при установленном 2026). Windows Update иногда предлагает такие «обновления».
- Драйверы видеокарты, чипсета, BIOS и EC ноутбука лучше брать с сайта производителя (команда `links`) — Windows Update их часто не содержит.
- Установка идёт по одному обновлению за раз в рамках одной сессии WUA; после неё может потребоваться перезагрузка.
- Бэкап восстанавливается командой: `pnputil /add-driver "<папка>\*.inf" /subdirs /install`.

## Логи

Все запуски пишутся в `%LOCALAPPDATA%\WinFix\logs\winfix-<дата>.log` (цвета удалены; удобно приложить при обращении за помощью).
