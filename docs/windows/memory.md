# memory — память

Показывает, как реально используется оперативная память, ищет «пожирателей» и утечки,
проверяет модули RAM и позволяет запустить тест памяти.

## Запуск

- Главное меню `winfix` → «Память».
- `winfix memory` — меню; `winfix memory report` — полный отчёт (обзор + топ + модули).

## Меню

| Команда | Пункт | Что делает |
|---|---|---|
| `overview` | Обзор | Физическая память, **commit** (выделено / лимит / пик), системный кэш, пулы ядра (paged/nonpaged), число процессов и дескрипторов, файл подкачки, режим подкачки (авто/ручной) |
| `top` | Топ потребителей | 15 самых «тяжёлых» программ (процессы с одинаковым именем суммируются — Chrome, Discord и т.д.) и поиск утечек: >20 000 дескрипторов или >4 ГБ private у одного процесса |
| `modules` | Модули RAM | Слот, объём, тип (DDR4/DDR5), реальная и номинальная частота, производитель; предупреждения об одноканальном режиме и недогоне до XMP; синие экраны за 60 дней |
| `pagefile` | Автоматический файл подкачки | Включает управление подкачкой Windows (нужен админ; вступает в силу после перезагрузки) |
| `test` | Тест памяти | Запускает штатный мастер `mdsched.exe` (проверка при перезагрузке) |
| `test-result` | Результат теста | Читает последний результат Memory Diagnostics из журнала |
| `wsl` | Ограничить WSL2/Docker | Создаёт `%USERPROFILE%\.wslconfig` с лимитом памяти (старый файл сохраняется как `.bak-…`), по желанию выполняет `wsl --shutdown` |
| `kill` | Завершить процесс | По PID, с подтверждением; системные процессы защищены |
| `report` | Полный отчёт | 1–3 подряд |

## Как читать результаты

- **Физическая память > 85–90 %** постоянно — закрывайте тяжёлые программы или добавляйте RAM.
- **Commit > 85 % лимита** — вот это уже опасно (ошибки «недостаточно памяти»). Решение: автоматический файл подкачки (`pagefile`), закрыть программы.
- **Nonpaged pool > 2 ГБ** — утечка в драйвере (антивирус, сетевой фильтр, виртуализация).
- Много памяти в «системном кэше» — это **нормально**: Windows использует свободную RAM как кэш и отдаёт её по требованию. Это не «утечка».
- Нормально, если файл подкачки используется слабо (десятки МБ) — Windows и так размещает его заранее.

## Чего утилита сознательно не делает

«Очистку оперативной памяти» (EmptyWorkingSet/Standby list) — она лишь вытесняет в подкачку нужные страницы, после чего программы работают медленнее. Реально помогает только закрытие программ, лимит WSL (`wsl`) и исправление утечек.

## Логи

Все запуски пишутся в `%LOCALAPPDATA%\WinFix\logs\winfix-<дата>.log` (цвета удалены; удобно приложить при обращении за помощью).
