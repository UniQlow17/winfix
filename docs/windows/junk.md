# junk — очистка мусора

Находит и удаляет временные файлы, кэши, дампы сбоев, старые логи и корзину.
Сначала **показывает**, сколько занимает каждая категория, и только после вашего выбора и подтверждения удаляет.

## Запуск

- Главное меню `winfix` → «Очистка мусора».
- `winfix junk` — меню; `winfix junk scan` — только посмотреть; `winfix junk clean` — найти и очистить.

## Как пользоваться

1. Подождите, пока завершится сканирование — появится таблица категорий.
2. Введите, что чистить:
   - `a` — все рекомендуемые категории;
   - `all` — вообще все, включая «по желанию»;
   - номера через запятую или диапазоны: `1,3,5-7`;
   - пустая строка — выход ничего не удалив.
3. Подтвердите удаление (`y`).

## Параметры командной строки

| Команда / параметр | Действие |
|---|---|
| `winfix junk scan` | только показать найденное, ничего не удалять (права админа не нужны) |
| `winfix junk clean --yes` | очистить рекомендуемые категории без вопросов (для планировщика задач) |
| `--all` | вместе с `--yes`: включить и категории «по желанию» |
| `--no-elevate` | не запрашивать UAC |

Пример для автоматической чистки по расписанию: `winfix junk clean --yes`.

## Что чистится

| Категория | Что именно | Примечание |
|---|---|---|
| Временные файлы пользователя | `%TEMP%`, INetCache | только файлы **старше 1 дня** |
| Временные файлы Windows | `C:\Windows\Temp` | старше 1 дня, нужен админ |
| Кэш Центра обновления | `SoftwareDistribution\Download` | службы `wuauserv`/`bits` на время останавливаются |
| Кэш оптимизации доставки | Delivery Optimization | |
| Дампы сбоев и WER | CrashDumps, Minidump, MEMORY.DMP, отчёты WER | |
| Старые журналы | `C:\Windows\Logs` `.log/.etl/.cab` | старше 30 дней |
| Кэш эскизов и значков | thumbcache / iconcache | занятые проводником файлы пропускаются |
| Кэши браузеров | Chrome, Edge, Yandex, Brave, Vivaldi, Opera, Firefox | **куки, пароли, история не затрагиваются**; закройте браузеры для полного эффекта |
| Кэши приложений | Discord, VS Code, Cursor, Steam | |
| Корзина | все диски | |
| *Кэши разработчика* | npm, pip, yarn, go-build, NuGet, cargo | по желанию — потом скачаются заново |
| *Шейдер-кэш видеокарты* | NVIDIA, D3D, AMD | по желанию — игры в первый запуск могут «подтормаживать» |
| *Хранилище компонентов (DISM)* | `StartComponentCleanup` | по желанию — долго |

## Безопасность

- Удаляется только то, что входит в белый список путей (см. таблицу). Загрузки, документы, Docker, пользовательские данные не затрагиваются.
- Защита от случайного удаления корня диска, `C:\Windows`, профиля пользователя и т.п.
- Файлы, занятые другими программами, пропускаются, ошибок не будет.
- Если установлен `C:\Windows.old`, утилита подскажет, как удалить его штатными средствами Windows.

## Логи

Все запуски пишутся в `%LOCALAPPDATA%\WinFix\logs\winfix-<дата>.log` (цвета удалены; удобно приложить при обращении за помощью).
