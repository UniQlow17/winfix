# network — сеть и интернет

Диагностика сети «одной кнопкой» и набор безопасных/осторожных способов починки:
шлюз, DNS, HTTP, прокси, сброс стека, подбор быстрого DNS, TCP-настройки.

## Запуск

- Главное меню `winfix` → «Сеть» (программа сама запросит права администратора).
- `winfix network` — меню; `winfix network diag` — только диагностика.

## Меню

| Команда | Пункт | Что делает | Риск |
|---|---|---|---|
| `diag` | Диагностика | Адаптеры (с пометкой VPN/виртуальных), IP/шлюз/DNS, ping шлюза / 1.1.1.1 / 8.8.8.8 (потери, мин/сред/макс), разрешение имён, HTTP(S)-проверки (включая NCSI Windows), прокси WinHTTP и пользователя, hosts, сетевые ошибки драйверов за 7 дней (с различием «идёт сейчас / было раньше»), Wi-Fi (сигнал, канал, скорость) | нет |
| `flush-dns` | Очистить DNS-кэш | `ipconfig /flushdns` | нет |
| `dns` | Подобрать быстрый DNS | Сравнивает системный DNS, Cloudflare, Google, Quad9, Яндекс, AdGuard (медиана, сбои) и по желанию ставит выбранный на адаптер | низкий |
| `traffic` | Трафик и соединения | Принято/отправлено по адаптерам, число соединений по процессам | нет |
| `dhcp` | Обновить IP (DHCP) | `ipconfig /release` + `/renew` | соединение пропадёт на секунды |
| `adapter` | Перезапустить адаптер | `Restart-NetAdapter` для выбранного физического адаптера | секунды |
| `tcp` | Настройки TCP | autotuning=normal, RSS=enabled, ECN=disabled | низкий |
| `winsock` | Сброс Winsock | `netsh winsock reset` | нужна перезагрузка, может сбить VPN |
| `ip-reset` | Сброс стека TCP/IP | `netsh int ip reset` + IPv6 | сбросит статические IP, может сбить VPN |
| `proxy` | Сброс прокси WinHTTP | `netsh winhttp reset proxy` | может сбить прокси-клиент |
| `full-reset` | ПОЛНЫЙ сброс сети | DNS + Winsock + IP + DHCP + предложение перезагрузки | как 8–9 |

## Рекомендуемый порядок при проблемах

1. **Диагностика (`diag`)** — смотрите, на каком уровне ломается: адаптер → шлюз → интернет по IP → DNS → HTTP.
   - шлюз не пингуется → проблема Wi-Fi/кабеля/роутера (`adapter`, перезагрузить роутер);
   - 1.1.1.1 пингуется, но имена не разрешаются → DNS (`flush-dns`, `dns`);
   - имена разрешаются, HTTP не работает → прокси/VPN/фильтр (`proxy`, `winsock`).
2. Мягкие меры: `flush-dns` → `adapter` → `dhcp`.
3. Жёсткие сбросы (`winsock`, `ip-reset`, `full-reset`) — только если мягкие не помогли.

## Про VPN и прокси

Если активен VPN/туннель (например, WireGuard, xray, OpenVPN), утилита это покажет и **предупредит перед каждым жёстким сбросом**.
После Winsock/IP-сброса перезагрузите ПК и заново запустите VPN-клиент.
Смену DNS утилита делает только на **физических** адаптерах — туннель не трогается.

## Ошибки драйвера сетевой карты

Если в диагностике (`diag`) видно «ошибки ПРОДОЛЖАЮТСЯ» у одного драйвера (например `rt25cx21` — Realtek 2.5GbE «Hardware IO error»),
это аппаратные/драйверные сбои шины, которые могут вызывать фризы системы. Лучше всего отключить неиспользуемый адаптер
(Диспетчер устройств или `Disable-NetAdapter`) или обновить драйвер у производителя ноутбука.

## Логи

Все запуски пишутся в `%LOCALAPPDATA%\WinFix\logs\winfix-<дата>.log` (цвета удалены; удобно приложить при обращении за помощью).
