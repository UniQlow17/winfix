# repair — ремонт Windows

Диагностика и восстановление целостности системы: системные файлы, хранилище компонентов,
файловая система, Центр обновления, WMI, Магазин, время, Defender.

## Запуск

- Главное меню `winfix` → «Ремонт системы» (программа сама запросит права администратора).
- `winfix repair` — меню; `winfix repair diag` — только диагностика (без админа); `winfix repair full` — диагностика + SFC + DISM + CHKDSK без меню.

## Меню

| Команда | Пункт | Что выполняется | Время |
|---|---|---|---|
| `diag` | Диагностика | реестр, `Get-PhysicalDisk`, `fsutil dirty`, службы, `winmgmt /verifyrepository`, журналы событий за 7 дней, `DISM /CheckHealth` | ~1 мин |
| `sfc` | SFC | `sfc /scannow` — понятный итог (чисто / восстановлено / не удалось) | 5–15 мин |
| `dism` | DISM | `/ScanHealth` + `/RestoreHealth` (нужен интернет) | 10–30 мин |
| `chkdsk` | CHKDSK онлайн | `chkdsk C: /scan` — без перезагрузки | 2–10 мин |
| `chkdsk-full` | CHKDSK полный | `chkdsk C: /F /R` на следующей загрузке (с вопросом о перезагрузке) | до часа |
| `wu-reset` | Сброс Windows Update | остановка служб, переименование `SoftwareDistribution` и `catroot2`, запуск служб | 1 мин |
| `wmi` | WMI | `winmgmt /verifyrepository` → `/salvagerepository` | 1 мин |
| `store` | Store и встроенные приложения | `wsreset` и перерегистрация AppX (лечит «Параметры», «Пуск», Магазин) | 1–5 мин |
| `time` | Время | запуск `w32time`, `w32tm /resync` | секунды |
| `defender` | Defender | обновление баз, быстрое сканирование | 1–10 мин |
| `full` | ВСЁ | диагностика → SFC → DISM → CHKDSK /scan | 30–60 мин |

## Что показывает диагностика

- ожидающая перезагрузка (CBS / Windows Update / PendingFileRenameOperations);
- здоровье дисков, температура, износ SSD, ошибки чтения/записи (от администратора);
- «грязный» бит тома, состояние ключевых служб, целостность WMI;
- дата последней установки обновлений;
- за 7 дней: Kernel-Power 41 (жёсткие перезагрузки), BugCheck, ошибки диска и NTFS, WHEA, TDR видеодрайвера, падения служб и приложений;
- рекомендации, какая команда или утилита поможет.

## Рекомендуемый порядок при проблемах с Windows

1. Диагностика (`diag`) → перезагрузка, если ожидается.
2. `dism` → `sfc` → `chkdsk`.
3. Если не помогло — сброс Центра обновления (`wu-reset`), Store (`store`).

## Безопасность

- Диагностика ничего не меняет.
- Сброс Центра обновления не удаляет установленные обновления и историю — только переименовывает кэш-папки (их можно вернуть из `*.bak-…`).
- Полная проверка диска и перерегистрация приложений всегда запрашивают подтверждение.

## Логи

Все запуски пишутся в `%LOCALAPPDATA%\WinFix\logs\winfix-<дата>.log` (цвета удалены; удобно приложить при обращении за помощью).
